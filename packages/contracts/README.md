# 공통 계약

첫 `mockprofile-100-a-v1` JSON Schema와 Python 계약 패키지를 추가했다. 스키마별 정규화는 온도·속도·경과시간을 유효한 십진 문자열로, 사건시각을 UTC ISO 8601로, 없는 선택적 오류 사유를 JSON null로, 출처 확장 숫자를 문자열로 만든다. 정규화 결과를 `rfc8785` 0.1.4로 직렬화하고 SHA-256을 계산한다. 업무 중복 키는 source ID·스키마 버전·record ID를 UTF-8 바이트 길이 접두어로 결합한다. 수신 ID·업무 키·내용 해시는 독립 필드다. 수치·시각·Null의 실제 적합성은 구현 후 교차 언어 시험으로 확인한다.

`jeyuk_process.py`는 승인된 제육볶음 소·중·대형 합성 프로파일의 하중·솥 표면온도·교반축 RPM·조리시간 경계와 1초 표본 기반 지속시간 판정을 제공한다. 연속 표본이 끊기면 판정기를 진행시키지 않고 호출자에 오류를 돌려주므로 5초 전송 평균으로 걸림·이탈 지속시간을 채우지 않는다. `jeyuk_mock.py`는 C# `mockprofile-110-a-001` 합성 원표본을 해석하며 출처·프로파일·필드·1초 간격을 검증한다. 이 계약은 DynamoDB·SQS 저장·안전 `75°C/60초` 판정이나 고객 작업 API에 아직 연결되지 않았다. 실제 제조사 사양을 뜻하지 않는다.
