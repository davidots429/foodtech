# 공통 계약

첫 `mockprofile-100-a-v1` JSON Schema와 Python 계약 패키지를 추가했다. 스키마별 정규화는 온도·속도·경과시간을 유효한 십진 문자열로, 사건시각을 UTC ISO 8601로, 없는 선택적 오류 사유를 JSON null로, 출처 확장 숫자를 문자열로 만든다. 정규화 결과를 `rfc8785` 0.1.4로 직렬화하고 SHA-256을 계산한다. 업무 중복 키는 source ID·스키마 버전·record ID를 UTF-8 바이트 길이 접두어로 결합한다. 수신 ID·업무 키·내용 해시는 독립 필드다. 수치·시각·Null의 실제 적합성은 구현 후 교차 언어 시험으로 확인한다.
